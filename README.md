# Navashakti Marketing — Production Website

Premium business website and interactive quotation generator for **Navashakti Marketing**.

## Quick Start (Local Development)

### Step 1: Open Terminal
Open your terminal (or VS Code terminal) in this folder.

### Step 2: Install Dependencies
Run:
```bash
npm install
```

### Step 3: Run Development Server
Run:
```bash
npm run dev
```

### Step 4: Open in Browser
Open `http://localhost:3000` to view the website.

---

## Deployment to GitHub & Vercel (Live in 3 Minutes)

### Step 1: Initialize Git and Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit of Navashakti Marketing production website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/navashakti-marketing.git
git push -u origin main
```

### Step 2: Deploy on Vercel
1. Sign in to [Vercel](https://vercel.com) using your GitHub account.
2. Click **"Add New..."** -> **"Project"**.
3. Select the `navashakti-marketing` repository.
4. Click **"Deploy"**.
5. Within 60 seconds, your site is live with a secure HTTPS URL!

### Step 3: Connect Custom Domain
1. In your Vercel Dashboard, go to **Settings** -> **Domains**.
2. Enter your purchased domain (e.g., `navashaktimarketing.com`).
3. Add the two DNS records (A Record `@` pointing to `76.76.21.21` and CNAME `www` pointing to `cname.vercel-dns.com`) at your domain registrar (GoDaddy, Namecheap, Hostinger, etc.).
